P / 01REAL-TIME VOICE · IN PROGRESS
N/

Nyquist

What does a voice agent need to handle an actual Telugu or Hindi call?

I built Nyquist so browser audio and incoming phone calls can run through the same streaming speech-to-text → language model → speech pipeline. It uses Bodhan Indic-Transcribe and Sarvam-30B APIs, with swappable TTS providers, not self-hosted models. The call path uses WebRTC and Vobiz media WebSockets; FastAPI, Docker, PostgreSQL and Redis support the service around it.

Higgs Audio v3
Telugu TTS

Telugu text was breaking into tiny byte fragments, and the resulting speech sounded flat. I tried ISO-15919 romanization before fine-tuning Higgs Audio v3 with LoRA. The resulting single-speaker voice generates without a reference clip. Rather than ask you to trust a claim about quality, I put eight approaches and their audio side by side.

03 / RESEARCH

A better answer to
"who spoke when?"

In my first-author IEEE CICN paper, we combined acoustic and contextual features to improve real-time and offline speaker diarization. The result was a 13% relative reduction in diarization error rate against the paper's baseline. Read the paper, inspect the slides or look at the code.
