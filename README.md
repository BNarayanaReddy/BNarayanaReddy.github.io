# Lakshmi Narayana Basireddy - portfolio

Static GitHub Pages user site. Source files are the site: no build step, dependencies, or framework.

## Preview locally

Run `python3 -m http.server 8000` in this folder and open http://localhost:8000/ . Alternatively open `index.html` directly. Edit copy in `index.html` and styles in `styles.css`.

## Hosting

The public GitHub repository is `BNarayanaReddy/BNarayanaReddy.github.io`. GitHub Pages serves this static site from the default branch root. The old `BNarayanaReddy/me` repository and `/me/` site were retired in a separate task; they are not part of this draft.

No private Nyquist source, credentials, unpublished materials or draft resume are included. Research DOI: 10.1109/CICN67655.2025.11368116.

## Publication assets

`real-time-offline-speaker-diarization-paper.pdf` is the 5-page camera-ready draft from Drive; `cicn-2025-presentation.pdf` is the 34-page final presentation PDF. The site links these local copies and the official DOI. Both PDFs include coauthor names and affiliations already in the paper. The paper is the author-accepted manuscript; its DOI citation and IEEE copyright notice are displayed beside the paper link on the site, per IEEE author-posting policy.
